# Custom CNN Implementation (Option D)

Этот каталог содержит реализацию агента с кастомной сверточной архитектурой для визуального управления (pixel-based reinforcement learning).

## Структура Проекта

### 1. `robot_env.py`: Среда Симуляции
Отвечает за физический мир, робота и генерацию данных.

*   **Класс `RobotArmEnv(gym.Env)`**:
    *   `__init__`: Инициализирует PyBullet, загружает робота Panda, объект-цель и настраивает виртуальную камеру.
    *   `step(action)`: Основной шаг симуляции. Принимает дельту координат (dx, dy, dz), применяет инверсную кинематику (IK), делает рендер кадра.
    *   `_render_frame()`: Получает RGB изображение 64x64, переводит в Ч/Б и **нормализует** (делит на 255.0), чтобы нейросеть получала данные в диапазоне [0, 1].
    *   `_get_observation()`: Формирует комбинированное наблюдение:
        *   `pixels`: Стек из 4 последних кадров (Frame Stacking) для отслеживания динамики движения.
        *   `proprioception`: Углы суставов робота.
    *   **Reward Function**: Использует плавную функцию награды (`1.0 - distance`), бонус за приближение (shaping) и бонус за касание.

### 2. `custom_cnn.py`: Нейросетевая Архитектура
Определяет ("мозг") агента.

*   **Класс `SmallConvExtractor(nn.Module)`**:
    *   Специализированная CNN для обработки изображений 64x64.
    *   Состоит из 3 сверточных слоев (Conv2d: 32 -> 64 -> 128 каналов).
    *   Эффективно извлекает пространственные признаки (положение манипулятора и цели) из пикселей.
*   **Класс `CustomCombinedExtractor(BaseFeaturesExtractor)`**:
    *   **Fusion Layer**: Объединяет визуальные признаки (от CNN) и проприоцептивные данные (от суставов).
    *   Позволяет агенту одновременно "видеть" ситуацию и "чувствовать" положение руки.

### 3. `train.py`: Скрипт Обучения
Отвечает за тренировочный процесс.

*   Использует алгоритм **PPO** (Proximal Policy Optimization).
*   Запускает 8 параллельных сред (`DummyVecEnv`) для ускорения сбора данных.
*   Обучает агента в течение 600,000 шагов.
*   Сохраняет чекпоинты модели каждые 50,000 шагов.

### 4. `test.py`: Скрипт Валидации
Используется для проверки качества обученной модели.

*   **Функция `evaluate_episodes`**: Проводит 50 тестовых эпизодов без визуализации для сбора статистики (средняя награда).
*   **Функция `replay_best_episodes`**: Визуализирует (рендерит) лучшие попытки агента в GUI окне, чтобы можно было оценить плавность и точность движений.
