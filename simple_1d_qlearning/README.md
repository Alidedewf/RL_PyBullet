# simple_1d_qlearning — самая первая версия

Ещё до Husky-навигации ([`main`](../../../tree/main)) и манипулятора Panda (эта ветка) — простейшая версия задачи: **коробка на прямой линии**, которую нужно пригнать к неподвижной цели силой влево/вправо, в PyBullet, табличным Q-Learning.

## Задача

- **Агент:** куб (`baseMass=1`), управляется приложением горизонтальной силы (`applyExternalForce`)
- **Действия:** 2 — толкнуть влево / толкнуть вправо
- **Состояние:** координата X агента
- **Награда:** `(старая_дистанция − новая_дистанция) − 0.1` за шаг, `+100` при подъезде ближе `success_threshold` к цели, `−10` при истечении лимита в 500 шагов

## Файлы

| Файл | Роль |
|---|---|
| `environment.py` | `SimpleEnv` — сцена PyBullet, физика, расчёт награды |
| `agent.py` | `QLearningAgent` — Q-таблица, epsilon-greedy |
| `main.py` | цикл обучения |
| `utils.py` | построение графика наград |

```bash
python main.py
```

Концептуальный предок [`main`](../../../tree/main) (Husky, 2D-навигация) и `curriculum_learning`/`custom_cnn_version`/`transfer_learning` в этой ветке (манипулятор, обучение по изображению) — тот же принцип «дистанция → награда», только в одномерном мире.
