# RL_PyBullet (dev) — тюнинг-итерация Husky-навигации

Та же задача, что в [`main`](../../tree/main): робот **Husky** в [PyBullet](https://pybullet.org/) учится доезжать до случайной точки табличным **Q-Learning**. Эта ветка — проход по настройке гиперпараметров и физики после того, как базовая версия на `main` заработала, но вела себя нестабильно (дёргано ездила, могла "зависать" на месте, слишком легко проезжала мимо цели).

## Что изменилось относительно `main`

| Проблема на `main` | Решение в `dev` |
|---|---|
| Робот "дёргался" — решение на каждом физическом шаге | **Action Repeat = 15**: одно решение агента удерживается 15 шагов физики подряд → плавное движение |
| Цель была "призрачной" (без коллизии, робот проезжал сквозь неё) | Целевая сфера получила `CollisionShape` — стала физическим препятствием |
| Агент мог просто стоять на месте без штрафа | Добавлен `IDLE_PENALTY` за выбор действия "стоп" |
| Сигнал за приближение был слишком "громким" относительно бонуса за цель | Пересчитан баланс наград: множитель дистанции 100 → 20, бонус за цель 10 → **100** |
| 250 шагов на эпизод — избыточно | Урезано до **100 шагов** (соответствует условию задания «достигает цели менее чем за 100 шагов») |
| `ALPHA = 0.5` — агент слишком резко переписывал Q-таблицу на шумных наградах | Снижено до **0.2** для более стабильного обучения |

Архитектура (`src/agent`, `src/environment/*`) не менялась — только `config.py`, `reward.py`, `task.py` и `base_env.py` (добавлен цикл Action Repeat в `step()`).

## Формула награды (обновлена)

```
R = (dist_old − dist_new) × 20 − turn_penalty − idle_penalty + goal_bonus
```

- `goal_bonus = 100` при `distance < 0.55` (было `10` при `< 0.3`)
- `idle_penalty = 0.5` за каждый шаг простоя
- `turn_penalty = 0.2` за разворот на месте

## Запуск

```bash
pip install pybullet numpy matplotlib
python train.py
```

Как и в `main`: сначала 1000 эпизодов обучения без GUI, затем 10 демонстрационных эпизодов с визуализацией на выученной политике. График наград сохраняется в `training_rewards.png`.

## Статус

Итерация тюнинга поверх `main` — тот же алгоритм (Q-Learning), но с исправленной физикой (плавность, коллизия цели) и перебалансированными наградами под более жёсткий лимит шагов.
